# jwt-decode-core

Decodificação de JWT SEM verificação: cabeçalho/payload, presença de
assinatura, expiração com relógio do chamador. Zero dependências, Node >= 22.

> Nunca use isto para autorizar nada. Decodificar não é verificar.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 3 testes, node:test, sem dependências
npm run demo
```

No máximo 32768 caracteres. MIT — veja `LICENSE`.
